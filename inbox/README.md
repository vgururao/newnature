# Inbox

Drop raw working materials here: notes, drafts, transcripts, voice memos, PDFs, screenshots,
whiteboard photos. Any shape, any name. Subfolders are fine.

- Files here are **raw** — Claude reads from them but never edits them in place.
- Text and markdown are committed to git; binaries and media (PDF, Word, images, audio, video, zip)
  stay in Dropbox only — see `../.gitignore`.
- URLs go in `../sources.md`, not here.
- Once a file has been worked through, note it in `processed.md` in this folder (file, date, where its material went).
